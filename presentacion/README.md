## 🖥️ Modo de Presentación Interactivo
Para ejecutar la presentación guiada de principio a fin sin tener que navegar manualmente entre páginas:
* Accede a la ruta `/presentacion` en la aplicación web.
* Utiliza los botones de navegación o las teclas de flecha `←` y `→` para transicionar fluidamente entre diapositivas.
* Cada diapositiva incluye un enlace directo a la sección especializada de cada integrante por si el profesor solicita profundizar en una demostración particular.
* Para el detalle de cada pantalla, consulta [guion-diapos.md](file:///c:/Users/dell5/UQV/Backend/expocision%20frontend/presentacion/guion-diapos.md).
