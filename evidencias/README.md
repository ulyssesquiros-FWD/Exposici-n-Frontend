# Evidencias Técnicas del Proyecto

Esta carpeta recopila las pruebas de ejecución, capturas de pantalla de funcionalidad y reportes de compilación de la plataforma de exposición.

## Registros Verificados
1. Inicialización limpia de repositorio Git con control de versiones.
2. Integración modular desacoplada mediante React Router.
3. Validación de compilación exitosa (`npm run build`).
4. Demostraciones interactivas ejecutables en tiempo real sin errores de consola.
